# PROJECT_A

프로젝트 파일 유형 설명

- [x] `cpp`  
  소스 코드 파일로, 프로젝트의 핵심 코드가 담겨 있습니다. 반드시 보존해야 합니다.

- [x] `sln`  
  솔루션 파일로, 여러 프로젝트를 포함하는 컨테이너 역할을 합니다. 삭제하면 안 됩니다.

- [x] `vcxproj`  
  Visual C++ 프로젝트 설정 파일로, 빌드 및 구성 정보를 포함합니다. 삭제 시 프로젝트 빌드에 문제가 생깁니다.

- [x] `vcxproj.filters`  
  프로젝트 내 소스 및 헤더 파일 분류 정보 파일입니다. 삭제하면 솔루션 탐색기에서 파일 분류가 사라질 수 있습니다.

- [o] `.vs`  
  Visual Studio 임시 설정 및 캐시 폴더로, 삭제해도 무방하며 필요 시 다시 생성됩니다.

- [o] `vcxproj.user`  
  사용자별 환경 설정 파일로, 삭제해도 무방하며 개인 설정이 저장됩니다.

> ※ `[x]` 표시된 파일은 삭제하지 마세요.  
> ※ `[o]` 표시된 파일은 삭제해도 프로젝트 작업에 영향을 주지 않습니다.
