# PROJECT_A

파일 유형 설명
[ x ] cpp: 소스 코드 파일로, 프로젝트의 핵심 코드가 담겨 있습니다. 반드시 보존해야 합니다.
[ x ] sln: 솔루션 파일로, 여러 프로젝트를 포함하는 컨테이너 역할을 합니다. 이 파일도 삭제해서는 안 됩니다.
[ x ] vcxproj: Visual C++ 프로젝트 설정 파일로, 빌드 및 구성 정보를 포함합니다. 삭제 시 프로젝트를 Visual Studio에서 열거나 빌드하는 데 문제가 생깁니다.
[ x ] vcxproj.filters: 프로젝트 파일 내 소스 및 헤더 파일 분류 정보가 담긴 파일입니다. 삭제하면 솔루션 탐색기의 분류가 사라질 수 있습니다.
[ o ] .vs
[ o ] vcxproj.user
o체크 파일만 삭제하시면 됩니다
